# CIS 8005: Reservation cancellation analysis

This shared project studies which reservations in a **synthetic Kaggle dataset** are associated with cancellation, then asks how a hotel could use a validated prediction to support pre-arrival decisions. Our working question is: **Which reservations are more likely to be canceled, and how could a hotel use that information to make a better operational decision?**

The source is Kaggle's [Binary Classification with a Tabular Reservation Cancellation Dataset](https://www.kaggle.com/competitions/playground-series-s3e7/data), Playground Series Season 3 Episode 7. Kaggle states that its train and test files were generated from a model trained on an earlier reservation dataset. Findings here describe the synthetic competition file and should not be presented as evidence about a specific hotel. The data page lists the files under a CC BY 4.0 license.

## Project files

- `data/raw/train.csv`: 42,100 labeled reservations; the only file used for exploratory cancellation rates and model validation.
- `data/raw/test.csv`: 28,068 unlabeled competition rows, reserved for possible later submission work.
- `data/raw/sample_submission.csv`: competition format example.
- `notebooks/00_data_preparation.ipynb`: shared, deterministic cleaning steps; generates ignored `data/processed/` CSVs.
- `notebooks/01_data_audit_and_eda.ipynb`: data audit, descriptive tables, and figures for work packages 1–3.
- `notebooks/02_modeling_and_evaluation.ipynb`: shared notebook for the planned predictive modeling, validation, and recommendation.
- `reports/analysis_handoff.md`: findings, limitations, cleaning decisions, and modeling questions.
- `reports/figures/`: charts generated by the notebook, with rates and group sizes shown together.

The three CSVs were downloaded from the competition's **Data → Download all files → Download as zip** on September 28, 2026. They are included as raw source files because the archive is small and this makes the analysis directly reproducible. We compared them byte for byte with the separately supplied `train.csv.zip`, `test.csv.zip`, and `sample_submission.csv`; all three match. Do not edit raw files; generated data belongs in ignored `data/processed/`. The SHA-256 digest for `train.csv` is `617098a2dcefa187e717f2fba56bb24e0b29f60949a88189ce390087343912ad`.

## Reproduce the exploration

Use Python with the packages in `requirements.txt` (`python -m pip install -r requirements.txt`). From the repository root, run the notebooks in this order in Jupyter or another notebook editor:

1. `notebooks/00_data_preparation.ipynb` reads the raw Kaggle CSVs and writes `data/processed/train_clean.csv` and `test_clean.csv` without changing or dropping raw values.
2. `notebooks/01_data_audit_and_eda.ipynb` checks the data and regenerates four PNG charts in `reports/figures/`. This is the completed work for the first three work packages.
3. `notebooks/02_modeling_and_evaluation.ipynb` contains the modeling plan and reads the same prepared training CSV. Results and recommendations will be added there.
